N진 탐색 알고리즘의 효율성과 하드웨어 상관관계 분석

Algorithms · Number Theory · Hardware · Optimization

탐구 동기

  • 이진 탐색을 일반화한 n진 탐색 구조의 수학적 분석
  • 실제 하드웨어 환경에서의 효율성 탐구
  • "왜 그런가"를 수학과 하드웨어 양쪽에서 설명

1. 수학적 모델링

  • 비교 횟수 모델링: f(n) = (n−1)/ln n
  • 이론적 최적값: 자연상수 e (≈ 2.718)
  • 정수 후보: n=2, n=3

2. 이론 vs 실제 — 왜 n=2가 표준인가

  • 탐색: n=3은 트리 깊이는 감소하지만 추가 비교 연산 필요
  • 비트 시프트(>> 1) 연산 불가 → 하드웨어 손실
  • 정렬: Java dual-pivot quicksort (n=3) 사례 분석
  • 대용량 데이터에서 n=3이 비교 횟수 약 10% 감소
  • 캐시 적중률 최적화로 이득

3. 도출한 통찰

  • 알고리즘 효율 = 수학적 연산량 + CPU 연산 구조 + 메모리 계층
  • 최적 알고리즘은 고정되어 있지 않음
  • 데이터 특성과 시스템 환경에 따라 유연하게 선택

핵심 흐름

이론(수학) → 검증(구현/실험) → 통찰(하드웨어 이해)

출제한 문제들

비트 마스킹

악성 코드 위치 찾기

  • 상황: 30개 서버 중 1개에 악성코드, 잠복기 1시간 분석기 5개
  • 조건: 단 1회 만에 위치 특정
  • 풀이: 분석기 5개를 이진법 5자리에 매핑
  • 소멸한 분석기 패턴 = 위치
  • 32개까지 확장 가능
참고: The 1,000 Wine Bottles Puzzle
동적 프로그래밍

2-Eggs Problem — 임계 전압 최소 테스트

  • 범위: 1~100MV 사이 임계 전압
  • 조건: 저항기 2개, 깨지면 끝
  • 풀이: 점진적 간격 전략
  • 1+2+…+N ≥ 100 → N=14
참고: 2-Eggs Problem
불변량

어두운 방의 동전

  • 상황: 앞면 10개·뒷면 90개 동전, 어두운 방
  • 조건: 10개 추출 후 양쪽 앞면 수 일치
  • 풀이: 추출한 10개 전부 뒤집기
  • 핵심: x ↔ 10−x 대칭성
참고: 100 Coins in a Dark Room

Tupper's 자기언급 공식 — 17의 의미

  • 주제: "자기 자신을 그리는 함수"
  • 질문: 공식 속 17의 역할
  • 정답: 비트맵의 높이
  • mod(y, 17) → 세로 길이 17픽셀 제한
참고: Tupper's self-referential formula

Activity · 2025

아두이노 입문 강연 — 사고뭉치(사뭉) 동아리

Arduino · Education · Public Speaking

강연 개요

  • 대상: 교내 동아리 '사고뭉치(사뭉)' 신입생 약 50명
  • 주제: 아두이노 입문
  • 방향: 도구의 필요성부터 직접 회로 동작까지

강의 구성

  • 아두이노란? — 마이크로컨트롤러 보드 개념, HW/SW 통합 환경
  • 회로의 기본 — 브레드보드, 저항·LED·점퍼선
  • 아두이노 IDE — 코드 작성, 업로드, 시리얼 모니터
  • 핵심 함수 — pinMode, digitalWrite, digitalRead, delay, analogRead
  • 실습 — LED 점등, 버튼 입력, 가변저항, 시리얼 통신
  • 응용 — 센서 기반 자동화 시스템 예시

강의 방식

  • 실습 위주 구성
  • 강의 시간 안에 직접 LED 점등·버튼 입력 체험
  • 하드웨어와 코드의 연결을 직관적으로 전달
